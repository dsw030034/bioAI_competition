# 课题思路与方法

**课题**：面向跨膜靶点的小分子生成算法设计｜**分工**：分子生成模块（含亚型选择性与膜蛋白性质的算法设计）｜2026-09-17

---

## 一、靶点与位点

**Nav1.8**，外周痛觉信号传导关键通道，主要表达于背根神经节伤害性神经元，中枢几乎不表达；临床有效性已验证（suzetrigine 2025-01 获 FDA 批准）。

**结合位点：孔道中央腔（site C）**，种子分子 **A-803467**——目前唯一有实验复合物结构的 Nav1.8 选择性孔道阻断剂（PDB 7WE4/7WFR 两种功能状态），对 Nav1.5 等亚型选择性 >100 倍。

Nav1.8 已映射的四个位点：**site C**（中央腔，A-803467，✅采用）、**site V2E**（VSDII 胞外口袋，suzetrigine >31,000 倍，但无实验结构、姿态仅由域交换实验与对接推断）、**site E**（胞外环，芋螺毒素多肽位点，不适用小分子）、**site BIG**（胞内门下方，卡马西平/布比卡因等非选择性镇痛药位点，❌与选择性目标冲突）。

> **术语澄清**：site C ≠ site BIG。本项目采用 site C；site BIG 是非选择性药物的结合处。

**配对反筛靶点：Nav1.5**。孔道抑制剂的真实心脏风险来自对 Nav1.5 的脱靶，而非 Nav1.8 自身的心脏表达。

## 二、决定算法设计的结构事实

7WE4/7WFR 的功能表征结论：**A-803467 的亚型选择性并非由配体接触残基决定**。配体在口袋内的直接氢键仅一处（PI 环 Gln355 与羰基氧），Tyr1717 为水介导，其余为疏水接触（Phe386、Phe1710、Met1713、Thr1659）；贡献选择性的是**不与配体接触**的残基（如 S6-I 的 Thr397）。而中央腔同时是局麻药与抗心律失常药的受体位点，在九个亚型间高度保守。

**三条设计原则**：
1. **静态口袋互补性打分不足以判别选择性**——"Nav1.8 打分 − Nav1.5 打分"的差值主要成分是噪声。
2. **选择性来源更可能在状态依赖与进入路径**——侧窗（fenestration）尺寸在亚型间有差异，分子可能塞得进腔体却只能从特定亚型的侧窗进入。这是动力学/可及性选择性，非热力学选择性。
3. **构象系综须按功能状态构建**（静息/失活/开放），而非随机多跑轨迹取快照。

## 三、工作流与筛选

```
输入已知药物 → 生成结构/性质相似的大批分子 → 分级打分筛选 → 迭代生成
```

**级联漏斗，严格由便宜到贵**：

| 层 | 内容 | 可计算层 | 成本/分子 |
|---|---|---|---|
| L0 | MW/logP/TPSA、QED、SA、PAINS、与种子相似度 | 2D | µs |
| L1 | 构象嵌入 → 膜性质（跨膜自由能代理、埋藏极性表面积） | 3D，无需蛋白 | 0.1–1 s |
| L2 | 双靶对接（Nav1.8 + Nav1.5，同协议） | 3D + 口袋 | 1–10 s |
| L3 | 选择性判决（ΔΔG，必要时自由能计算复核） | 3D + 口袋 | 分钟–小时 |

**约束施加有两条独立的轴**：一是约束在哪一层**可计算**（2D 拓扑 → 3D 构象 → 3D+口袋），二是在流程哪个位置**施加**（解码时硬约束／生成后过滤／迭代 reward）。一个 2D 可算的约束（如分子量）既可放解码时也可做成 reward，位置是设计选择。

> **数量控制的大头在生成环节，判断力的大头在筛选环节。**

## 四、生成模块路线

**化学语言模型（SMILES 自回归）+ 反应模板接地。**

任务学名为 **SCMG**（结构约束分子生成）：生成与给定分子结构相似但性质被优化的新分子。选字符串路线而非 3D 生成路线，因为 3D 坐标由下游对接产生、无需生成器承担，且 3D 生成赛道已饱和。叠加反应模板接地以保证**可合成**并给出合成路线。工程底座采用开源框架，其打分组件为可插拔设计，**选择性与膜性质可作为自定义组件接入，无需改动模型架构**。已知缺陷：字符串模型会生成语法非法分子，故先按 SMILES 走并监控有效率，低于 ~90% 再考虑 SELFIES 或语法约束解码。

## 五、两个差异化设计

**5.1 亚型选择性**——注入位置分三层递进：(A) 作为打分项 `reward = w₁·相似度 + w₂·选择性分 − w₃·脱靶惩罚`；(B) 作为条件变量（目标亚型与要求的选择性倍数）；(C) 作为配对任务直接学习决定选择性的结构要素。

关键选择：鉴于第二节事实，代理模型应学习 **ΔΔG（差值）而非绝对亲和力**——差值数据需求小，且两靶误差部分抵消。这正是与现有工作的区别：现有选择性感知生成方法普遍隐含"选择性可由口袋接触互补性表达"的假设，该假设在 site C 上不成立。

可选组合：**site C 结合 + 侧窗可通过性约束**（分子最大横向截面 ≤ 目标状态侧窗尺寸），相当于把动力学选择性机制编码进生成模型。

**5.2 膜蛋白性质**——三层落地：① 描述符阈值（logP/logD、TPSA、MW、跨膜自由能代理分）作惩罚项；② 接入基于热力学机制的膜渗透性预测模型替换粗糙阈值；③ 将"位点在膜中的深度/脂质暴露程度"作条件输入。

> **须避免的误区**：膜蛋白性质 ≠ 分子更亲脂。一味提高 logP 会致溶解度崩溃、代谢变差、毒性上升。约束必须是**双向区间**并与类药性联立评价。

## 六、迭代机制

**概念先明确**：好分子本身不是 reward，reward 是数字（对接分数、选择性倍数、QED）；问题是这个数字**回灌去更新什么**。四种去向：

| 方案 | 更新对象 | 原理 | 采用顺序 |
|---|---|---|---|
| 渐进式微调 | 数据（种子集） | 按活性从低到高逐步引入分子增量微调 | **第一优先**：最简最稳 |
| 遗传算法/分子转换 | 操作策略 | 维护分子池，反复施加药化式转换后选优 | **第二优先**：可解释性最好，能产出"改哪个基团→活性变多少" |
| RL + 对接奖励 | 生成器权重 | 生成器为 agent，打分为 reward；先验网络作约束 | 主力，用现成框架 |
| 主动学习 | 打分代理模型 | 每轮只送最有信息量样本算昂贵真值，回标重训代理 | 打分昂贵时启用，可与 RL 叠加 |

RL 路线采用双网络：先验网络（预训练后冻结，代表"类药分子长什么样"）与智能体网络（唯一被更新）。损失中先验项起"弹簧"作用，防止智能体退化为只会刷分；该系数是首要调参项。

## 七、须规避的四个问题

1. **奖励黑箱化**：对接打分偏好大分子，模型会靠增大分子刷分 → 加分子量惩罚，或用多目标 Pareto 前沿而非线性加权。
2. **奖励噪声与信号同量级**：对接误差常 1–2 kcal/mol，而要分辨的选择性差异也在此量级 → 主动学习/真值校准非可选项；AI 打分角色是**分诊而非判决**。
3. **多样性坍缩**：迭代数轮后分子趋同 → 批内多样性纳入 reward，或每轮保留随机采样比例。
4. **构象嵌入失败被当低分回灌**：模型会学到采样器偏差而非化学 → 每分子生成 5–10 构象取最优，失败者单独标记，**不可当 0 分**。

## 八、评价原则

新颖性**不许单独报**，须与约束侧成对（新颖性 ↔ 逆合成通过率；类药性 ↔ 膜环境适配）；类药性**报分布不报均值**；选择性须报 **ΔΔG 及两靶误差相关系数**（单靶 RMSE 不作数）；**所有对比实验固定库规模**（库规模本身会显著扭曲评价）；**基线须含廉价基线**（MW/logP/TPSA/指纹 QSAR），避免把基线红利记在方法上；数据切分做骨架不相交划分并检查与常用训练集的相似性以防泄漏。
