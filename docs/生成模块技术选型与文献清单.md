# 生成模块技术选型与文献清单

> 对应组内工作流：**输入已知药物 → 生成结构/性质相似的大批分子 → 打分筛选(docking) → 迭代**
> 你负责第一环（生成）+ 选择性/膜蛋白性质的算法设计；迭代方式待定，本文给出四个选项。
> 版本：2026-09-17。规则：**先读文献，再动手。**

---

## 0. 先回答你的问题："把结构写成语法/符号再统计预测"是什么

你的直觉是对的，这条路有正式名字：**化学语言模型（Chemical Language Model, CLM）**，也叫基于 SMILES 的自回归生成。

**白话解释**：把一个分子写成一串字符（SMILES，例如苯环就是 `c1ccccc1`），然后像训练 ChatGPT 写文章一样，训练模型"接着写下去"。模型学到的是"字符之间的统计规律"，而这个规律恰好编码了化学合理性——所以它写出来的字符串，大多数能还原成合法的分子。

这就是你猜的"统计预测"，只不过预测的下一个 token 是化学符号而不是文字。

**一个必须先知道的坑**：字符串模型会写出**语法错误**的分子（比如括号不配对、价态超限），这叫 validity（有效率）问题。有两种解法，记住它们的取舍：
- **SELFIES 表示**：一种"绝对不会写出非法分子"的符号系统，语法层面就保证了有效性，但表达能力和生态不如 SMILES。
- **保留 SMILES + 后过滤**：生成后丢掉非法的，简单但浪费算力。
> 决策建议：**先按 SMILES 走**（生态最全、教程最多、REINVENT4 默认支持），把有效率作为一个指标监控；如果发现有效率低于 ~90%，再考虑换 SELFIES 或加语法约束解码。

## 1. 方法家族树：四条路线，你该选哪条

| 路线 | 怎么表示分子 | 代表模型 | 优点 | 缺点 | 适合你们吗 |
|---|---|---|---|---|---|
| **① 字符串（CLM）** | SMILES/SELFIES 序列 | REINVENT、MolGPT、REINVENT-Transformer、LDMol | 上手最快、生态最全、显存需求低、天然支持"给条件生成" | 有效率问题；不显式建模 3D | ✅ **主推** |
| **② 图（Graph）** | 原子-键图，逐原子/逐键生长 | JT-VAE、GFlowNet 类 | 化学合理性天然更好 | 实现复杂、慢、可合成性需额外处理 | 备选 |
| **③ 反应/片段接地** | 用真实反应模板拼接片段 | **LibINVENT**、**ClickGen**(Nat Commun 2024)、Synthesizable-by-Design(2025) | **生成的分子保证可合成**、能给出合成路线 | 受限于反应模板库 | ✅ **强烈建议叠加**（见 §3） |
| **④ 3D/结构基** | 原子三维坐标 | ResGen、DiffBP、EDM、DiffSMol | 直接建模口袋几何 | 显存大、复现难、3D 指标普遍差 | ❌ 你这一环不用，留给打分环节 |

**给你的结论**：走 **①+③ 组合**——用 SMILES 语言模型做主干，用反应模板约束保证可合成。理由是你们的目标是"结构相似的大批分子 + 可筛选"，不需要 3D 坐标（3D 的事交给后面的 docking 环节去做）。这个组合在 4090 24GB 上完全跑得动。

## 2. 你这一环的正式任务名与直接可参考的工作

任务学名：**SCMG（Structure-Constrained Molecular Generation，结构约束分子生成）**，也叫 reference-guided / ligand-based conditional generation。定义就是你们要的：**生成与给定分子结构相似、但性质被优化的新分子**。

可直接对标的文献（按参考价值排序）：

| 文献 | 它做了什么 | 你能抄什么 |
|---|---|---|
| **PURE**: policy-guided unbiased REpresentations for structure-constrained molecular generation (2025) | 专攻 SCMG，明确指出"偏向已有知识"和"离散分子与深度学习的阻抗失配"两大问题 | 问题定义与失败模式的分析框架 |
| **RefProgen**: reference-guided generation with protein-ligand joint representation (Expert Syst. Appl. 2026) | 用参考分子 + ECFP Tanimoto 检索 Top-K 施加约束，评价时明确用 QED≥0.6、SA≤4.0 | **约束的施加方式和评价指标口径**，跟你们流程最像 |
| **CMGN**: conditional molecular generation net (Brief Bioinform 2023，协和) | 双向自回归 Transformer + 预训练/微调范式 | 国内团队的可复现范例 |
| **Enhancing Conditional Molecular Generation with Pretrained SMILES Transformer and Contrastive Representation Learning** (2026) | 用对比学习抓"不变表示"来做条件生成 | 条件编码的技术升级路线 |
| **Molecular optimization using a conditional transformer for reaction-aware compound exploration with RL** (Commun. Chem. 2025) | **条件 Transformer + 反应感知 + RL**，几乎是你们流程的完整实现 | ⭐ 精读，架构可整体借鉴 |

## 3. 主力工具推荐：REINVENT4（重要）

**为什么是它**：REINVENT4（AstraZeneca 开源，*J. Cheminf.* 2024，被引 500+）一个框架同时提供了你需要的三样东西：

1. **生成器**（支持 RNN / Transformer / LibINVENT / REINVENT-Transformer 多种骨干）；
2. **可插拔的打分组件（scoring components）**——这是关键：你可以写自定义打分函数插进去，包括"亚型选择性"和"膜蛋白性质"；
3. **迭代优化循环**（内置 RL：agent–prior 结构，把打分回灌去微调生成器）。

**这直接回答了你们组"迭代方式还没想好"的问题**——迭代可以先用现成的，把精力集中在打分组件的设计上。

配套必读：
- REINVENT4 原文（*J. Cheminf.* 2024）——只看架构和 scoring component 两节
- **ClickGen**（浙大侯廷军/谢昌谕团队，*Nat. Commun.* 2024）——基于**模块化反应 + RL** 定向探索可合成化学空间。这是"③反应接地 + ①RL"结合的标杆，和你们"新颖但做得出来"的需求高度契合
- **Synthesizable by Design: A Retrosynthesis-Guided Framework for Molecular Analog Generation**（2025, arXiv:2507.02752）——逆合成引导的类似物生成，专门解决"生成的分子合成不出来"

## 4. 差异化设计之一：亚型选择性怎么注入生成器

有**三个可注入的位置**，难度递增，建议按顺序试：

### 位置 A：作为打分项（最简单，先做这个）
```
reward = w1·similarity(参考分子) + w2·选择性分 − w3·脱靶惩罚
选择性分 = f(Nav1.8 打分) − f(Nav1.5 打分)
```
文献依据：
- **MolSculptor**: Adaptive Diffusion–Evolution Framework for Multitarget Affinity and Selectivity (*J. Chem. Theory Comput.* 2026)——**直接以"选择性"为一等目标**的生成框架，用 3D-aware 代理模型加速
- **ALPAQAFlow**（OpenReview）——selectivity-aware 生成 + 库筛选对比
- **ParetoDrug**: target-aware generation with Pareto MCTS (*Commun. Biol.* 2024)——**多目标不硬加权，而是取 Pareto 前沿**。当"亲和力"和"选择性"互相冲突时，这个思路比线性加权更稳，强烈推荐了解
- **EVOSYNTH**: latent evolutionary optimization + synthesis-aware prioritization (*Commun. Chem.* 2026)

### 位置 B：作为条件变量（中等）
把"目标亚型 / 要求的选择性倍数"作为 token 喂给模型，训练时学习"条件→结构"的映射。
- 参考 **LaMGen**（*Nat. Commun.* 2026）——LLM 驱动的**多靶点** 3D 生成，配套开源数据集 MTD2025（4011 蛋白、12.3 万分子、60 万构象、44.6 万条双靶点关联）。**这个数据集你们可以直接拿来训练/评测**，省掉自建数据的成本
- **DeepDTAGen**（*Nat. Commun.* 2025）——多任务框架同时做亲和力预测和靶点感知生成

### 位置 C：把选择性做成"配对任务"（最难，但最像你们的真实场景）
⭐ **最值得精读的一篇**：
**AI-driven generative framework integrating ML-QSAR and fragment learning for isoform-selective PI3K inhibitor design**（*J. Comput.-Aided Mol. Des.* 2026）

理由：这是**目前唯一一个把"亚型选择性（isoform selectivity）"作为核心目标**的生成框架，明确讨论了"同一家族不同亚型间的交叉反应与脱靶"问题，用 ML-QSAR + 片段学习定位"决定选择性的结构要素"。**PI3K 有 α/β/γ/δ 四个亚型，和你们 Nav 家族的亚型选择性问题在数学结构上完全同构**——它的方法论可以整体迁移。

> 补充：*Machine Learning for De Novo Molecular Generation: A Comprehensive Review*（*ACS Chem. Neurosci.* 2026）摘要里明确提到"isoform selectivity and minimizes off-target neurotoxicity"，说明这个方向正在成为共识关注点，但工具仍稀缺。

## 5. 差异化设计之二：膜蛋白性质怎么变成可计算约束

**检索结论（重要）**：我专门查了"是否有生成模型显式注入膜环境/跨膜口袋约束"——**没有找到任何一篇**。这个空档是真实存在的。但组成零件是现成的，你的工作本质是**组装 + 权重设计**：

| 你需要的能力 | 现成的文献/工具 | 用途 |
|---|---|---|
| 膜渗透性预测（可解释、有热力学机制） | **蒋绪恺团队，*J. Med. Chem.* 2026**：thermodynamics-based DL framework，GNN + 跨膜自由能 | ⭐ 直接当"膜性质打分器"，比自己训靠谱 |
| 膜内自由能剖面 → ML | **SILCS + AI 高通量被动渗透预测**（2026） | 提供物理特征，可做代理模型 |
| 隐式膜模型 + ML | *JCIM* 2019：implicit membrane model + ML 预测 logPm，用 PAMPA 实验值验证 | 低成本基线做法 |
| 渗透性多任务学习 | *Prediction of permeability and efflux using multitask learning*（2025）：多任务 MPNN + 预测 logD/pKa 增强 | 数据少时的增强技巧 |
| 膜结合分子对接的特殊性 | **Open-Source Molecular Docking and AI-Augmented SBDD: Current Workflows, Challenges, and Opportunities**（*IJMS* 2026）——明确指出膜结合分子的取向与双层耦合，需要 **membrane-aware docking** | 支撑你们"跨膜口袋不同于可溶蛋白口袋"的论点 |
| 脂质面口袋成药的真实先例 | **A1 腺苷受体脂质面别构口袋 PAM 的结构基础发现**（*PNAS* 2025） | 证明"面向脂质双层的口袋可成药"不是空想 |
| 膜蛋白设计的亲脂性能量函数 | *A lipophilicity-based energy function for membrane-protein modelling and design*（*PLoS Comput. Biol.* 2019） | 约束项的物理形式可参考 |

**落地建议（三层，从易到难）**：
1. **第一层（先做）**：把膜性质降维成一组分子描述符阈值——logP/logD、TPSA、分子量、以及"跨膜自由能代理分"。作为打分组件的惩罚项。几乎零额外算力。
2. **第二层**：接入上面那个热力学约束的膜渗透性预测模型，替换掉粗糙的描述符阈值。
3. **第三层（有余力再做）**：把"口袋在膜中的深度位置"（脂质暴露程度）作为条件输入——这需要子任务1 的构象数据配合，属于加分项。

> ⚠️ 一个必须避免的误区：**"膜蛋白性质"不等于"分子要更亲脂"**。一味提高 logP 会让分子变得不可成药（溶解度崩、代谢差、毒性升）。所以约束必须是**双向的**（区间约束，不是越大越好），并且要和类药性指标（QED）联立评价。这一点写进方案能显示你们懂行。

## 6. 迭代方式：四个选项与建议

| 方案 | 原理 | 难度 | 代表文献 | 我的建议 |
|---|---|---|---|---|
| **A. 渐进式微调** | 按活性从低到高**逐步**引入分子做增量微调，让模型自然偏向高活性结构，**无需外部打分函数** | ★ | **Nat. Commun. 2026-04：渐进式语言模型驱动的药物结构优化**（中文导读见腾讯云 DRUGONE） | ⭐ **第一个做**。实现最简单、结果最稳、最容易讲清楚 |
| **B. 遗传算法 / 分子转换迭代** | 维护一个分子池，反复做"药化式转换"（换基团、加环、封位），用打分选优 | ★★ | **DockingGA**（*Brief. Bioinform.* 2024）；**RL-guided GA integrating medicinal chemistry-inspired transformations**（*JCISD* 2026，从源分子迭代施加采样到的转换）；**Reinforced GA for SBDD**（NeurIPS 2022，有开源代码） | ⭐ **第二个做**。可解释性最好，能直接产出"改了哪个基团→活性变了多少"的表，这正是你们要的科学结论 |
| **C. RL + docking 奖励** | 生成器作为 agent，docking/性质分数作为 reward，回灌微调 | ★★★ | **REINVENT4**；**ClickGen**（*Nat. Commun.* 2024）；**Mol-air**（自适应内在奖励，2025）；**A2C + 物化性质 + docking 奖励**（2023） | 主力方案，但先用 REINVENT4 现成的，别自己实现 |
| **D. 主动学习 / 增强记忆** | 每轮只把最有信息量的样本送去算昂贵的真值，省算力 | ★★★ | **Augmented Memory**（2024）；**Sample-efficient RL with active learning**（*Digital Discovery*，加速 4–64 倍）；**Optimal molecular design: REINVENT + 结合自由能主动学习**（*JCTC* 2024） | 加分项。算力紧张时再上 |

### ⚠️ 迭代的三个已知陷阱（读文献时重点看）
1. **奖励黑箱化（reward hacking）**：拿 docking 分数当奖励时，模型会学会钻漏洞——最典型的是**生成越来越大的分子刷分**（对接打分函数天然偏好大分子）。对策：加分子量/重原子数惩罚，或用 Pareto 多目标而非单标量。*Machine learning-aided generative molecular design*（*Nat. Mach. Intell.* 2024）明确讨论了这个现象。
2. **多样性坍缩**：迭代几轮后生成的分子会越来越像，库的覆盖度掉光。对策：把"批内多样性"也放进奖励，或每轮强制保留一定比例随机采样。
3. **评价口径混淆**：生成库的**规模本身会扭曲指标**（库越大，越容易碰到高分分子，看起来"效果更好"）。已发表的批评文献：*How evaluation choices distort the outcome of generative drug discovery*。**对策：所有对比实验固定库规模，并报随机分子基线。**

## 8. 你这一环的接口设计（写代码前先定下来）

**输入**
- 种子分子：已知药物 / 先导化合物的 SMILES 列表（如 A-803467、美西律、氨溴索）
- 约束参数：目标相似度区间、QED 下限、SA 上限、膜性质区间、目标亚型

**输出（交给打分筛选环节）**
- 分子 SMILES + 3D 构象（docking 需要）
- 每个分子的元数据：生成来源（哪个种子、第几轮迭代）、施加的转换、可合成性标记与逆合成路线、各项打分的预测值
- ⚠️ **元数据是"数据库"和"一堆 SMILES"的区别**，从第一版就要设计好字段

**评价指标（必须成对报，防刷分）**
| 维度 | 指标 | 说明 |
|---|---|---|
| 相似性 | Tanimoto（ECFP4/Morgan）到种子分子 | 你们的核心约束 |
| 新颖性 | 与 ChEMBL/训练集的最近邻距离、骨架不相交比例 | 必须用 Bemis-Murcko 骨架层面 |
| 有效性 | validity（RDKit 能否解析）、uniqueness | 字符串模型的生命线 |
| 类药性 | QED、SA、MW/logP/TPSA 分布 | **报分布图不报均值** |
| 可合成性 | SAscore、逆合成通过率（AiZynthFinder） | ⭐ 和 novelty 成对报，防"刷新颖度" |
| 多样性 | 批内 Tanimoto 分布、骨架数 | 防迭代后坍缩 |

## 9. 一句话总结给你汇报用

> 我们的生成模块走**化学语言模型（SMILES 自回归）+ 反应模板接地**的路线，以 REINVENT4 为工程底座；创新性在于把两个此前未被生成模型显式编码的约束——**同家族亚型选择性**与**跨膜环境的膜性质**——做成可插拔的打分组件，并采用"渐进式微调 + 药化式转换迭代"的闭环，使生成的分子同时满足新颖、可合成、类药、膜环境适配四项要求。
