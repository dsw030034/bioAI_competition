## Nav1.8：脂质对照支持此前的原因假设

| 受体模型 | 第一名通过 | 第一名 RMSD 中位数 |
|---|---:|---:|
| 既有纯蛋白基线 | 11/15 | 0.919 Å |
| 蛋白＋截短 LPE，两性离子状态 | 15/15 | 0.905 Å |
| 蛋白＋截短 LPE，CCD 酸形式对照 | 15/15 | 0.905 Å |

这三组使用相同五个初始配体和三个随机种子。原 4 个错误第一名全部恢复到近原生位置，
脂质碰撞消失；两种头部状态的 15 组完整输出姿势哈希相同。
比较的是 Vina 原始第一名，没有按参考 RMSD 重排。

LPE 只保留 22 个实验重原子，C16 以氢封端，没有猜测未解析的 12 个尾链碳。
这是固定截短脂质的匹配原因对照，尚不是新输入/新种子的独立验证，也不代表完整膜环境。
详细化学建模、限制与重现命令见 [Nav1.8 说明](nav18_details.md)。

## Nav1.5：实验附近可以保留，但错误位置仍获更好分数

| 同一局部优化模式 | 中性奎尼丁：分数 / RMSD | 奎尼丁 +1：分数 / RMSD |
|---|---:|---:|
| 从实验姿势起步 | −6.679 / 1.461 Å | −6.676 / 1.472 Å |
| 从既有错误第一名起步 | −8.477 / 10.189 Å | −8.273 / 11.281 Å |

实验起始组优化后恢复全部原接触残基，错误第一名组恢复率仍为 0%。
当前受体＋配体几何＋Vina 模型仍偏爱错误区域，仅增加搜索量未必能解决。
这是诊断，不是 Nav1.5 重对接通过：已知实验位置作为输入提供，不能计入独立成功率。
分数是 Vina 模型值，不是实测结合自由能。详细表格和限制见 [Nav1.5 说明](nav15_details.md)。
