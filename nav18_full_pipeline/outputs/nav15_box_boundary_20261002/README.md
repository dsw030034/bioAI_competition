# Nav1.5 局部搜索盒边界对照

复用匹配构象实验的 8 个 `rdkit_addhs` 配体输入，仅将局部搜索盒从 24 Å 扩至 28 Å；受体、中心、评分权重、种子和 CPU 设置相同。8 项计算全部成功，生产代码散列未变。已知位点作为初始摆放，因此这不是独立重对接验证。

| 状态 | 起始构象 | 位点 | 24 Å 分数 | 28 Å 分数 | 28 Å RMSD |
|---|---|---|---:|---:|---:|
| 中性 | 实验 | 实验 | -6.679 | -6.616 | 1.690 |
| 中性 | 实验 | 错误 | -6.255 | -6.157 | 10.122 |
| 中性 | 错误姿势 | 实验 | -6.263 | -6.245 | 1.713 |
| 中性 | 错误姿势 | 错误 | -8.477 | -8.449 | 10.105 |
| +1 | 实验 | 实验 | -6.676 | -6.594 | 1.679 |
| +1 | 实验 | 错误 | +0.763 | -6.503 | 11.212 |
| +1 | 错误姿势 | 实验 | -5.841 | -5.758 | 2.306 |
| +1 | 错误姿势 | 错误 | -8.273 | -8.298 | 11.344 |

分数单位为 kcal/mol，RMSD 为相对实验姿势的固定坐标系重原子 RMSD，单位 Å。28 Å 所有终点均没有重原子对距离小于 2 Å；错误位点的实验残基接触召回仍为 0，没有恢复实验位点。

原 24 Å 的两个 +1 错位点终点均有一个重原子压在 x 边界。保存坐标因三位小数舍入，离名义边界为 -0.000125 Å；这不是精确的优化内部坐标。显式氢离原盒边界最近分别为 3.922、4.949 Å，不是氢越界。Vina 1.2.7 `vina.cpp:335` 定义格网越界斜率 `1e6`，边缘的微小偏移可能产生显著数值惩罚，不能把原 +0.763 解读成真实位点排斥。

扩大盒后 +1 实验构象在两位点的局部分差仅 0.091 kcal/mol。28 Å 的所有终点离名义盒边界至少 2.006 Å；无需再扩大盒来处理贴边。但用错误姿势内部构象起始时，错误位点仍比实验位点得分更低，当前诊断没有解决自动姿势选择问题。

`minimum_face_margin` 均为到**请求的名义盒边**的带符号距离：正值在内，负值在外。Vina 会按 0.375 Å 网格间距向上取整实际范围；默认不强制偶数体素时，28 Å 请求对应 28.125 Å 实际网格。这里的名义边界余量较实际网格余量保守，不影响未贴边结论。改变盒尺寸也会改变格点位置，远离边界的微小分数差不能全部归因于边界惩罚。

运行后仅修正了摘要字段名 `output_minimum_face_margin_to_original_24_A` 和元数据说明，没有重跑或改写 Vina 输入、日志或姿势。`manifest.json` 保留运行时 `script_sha256`，另记 `final_script_sha256`。
