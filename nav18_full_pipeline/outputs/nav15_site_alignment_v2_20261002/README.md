9V3S 的 A1EQU 仅映射实验原子的坐标；CCD 化学图存在 N–N 单键与实验 cis-azo 的冲突。本目录没有将该配体输出为已验证的化学 SDF，不能用于已验证的重对接。

同源映射只能说明位置关系。6UZ0 为大鼠 Nav1.5，7WE4 为 Nav1.8，9V3S 配体与构建体不同；重叠不能证明相同结合方式、亲和力或功能风险。整体/局部配准差异和残基对应已完整保存在 JSON，供审查。
